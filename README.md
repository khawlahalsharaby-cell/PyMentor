# 🐍 PyMentor

**An AI-Powered Interactive Python Learning Assistant**

PyMentor is an educational project designed to help beginners learn Python through AI-powered explanations, interactive exercises, quizzes, and progress tracking.

## ✨ Features

- 🤖 AI-powered Python tutor.
- 📚 Organized Python learning topics.
- 💻 Interactive exercises with explanations.
- 📝 Quizzes and score results.
- 📊 Learning progress tracking.
- 💬 Chat history management.
- ⚙️ Learning settings and hints.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Python
- FastAPI
- Google Gemini API

## 📁 Project Structure

- `frontend/` — User interface.
- `backend/` — Python API and AI integration.
- `README.md` — Project documentation.

## 🚀 Getting Started

1. Install Python.
2. Install the dependencies using `pip install -r requirements.txt` from the backend directory.
3. Create a private `.env` file containing your Gemini API key.
4. Run the backend using `python -m uvicorn main:app --reload`.
5. Open the frontend in your browser and configure the API URL if needed.

## 🎯 Goal

PyMentor combines AI assistance, Python practice, quizzes, and progress tracking to make learning programming more interactive.

## 🔐 Security

Never upload your `.env` file or expose your API key on GitHub.
